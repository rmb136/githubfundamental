Chapter 1: Introduction to Git and GitHub
1) Q: What is Git and why is it used?
   A: A distributed version control system for tracking changes.
2) Q: How does Git differ from GitHub?
   A: Git is the VCS; GitHub is a hosting/collaboration platform built on Git.
3) Q: Define a repository in your own words.
   A: A storage for project files and their history.
4) Q: What information does a commit store?
   A: Commit stores a snapshot of changes, message, author, timestamp.
5) Q: Explain what a branch is.
   A: A parallel line of development to isolate work.
6) Q: What does cloning a repository do?
   A: Creates a local copy of the remote repository.
7) Q: Name two benefits of version control.
   A: History, collaboration, backup; example: safe experimentation and rollback.
8) Q: What is the purpose of a commit message?
   A: To explain what changed and why; helps reviewers.
9) Q: How would you view the commit history of a repo?
   A: Use git log or git log --oneline to view history.
10) Q: Give an example scenario to create a branch.
   A: When developing a new feature, to avoid affecting main branch.

Chapter 2: Setting Up Git and GitHub
1) Q: How do you install Git on a machine? (list common methods)
   A: Download from git-scm.com, use package managers (apt, brew, choco), or GitHub Desktop.
2) Q: What commands set your Git username and email?
   A: git config --global user.name "Your Name"; git config --global user.email "you@example.com"
3) Q: Why is configuring your email important for commits?
   A: So commits link to your identity and show on GitHub profile.
4) Q: What is GitHub Desktop used for?
   A: A GUI client to manage repos locally and sync with GitHub.
5) Q: Describe one benefit of the GitHub CLI.
   A: CLI enables scripting and faster workflows for advanced users.
6) Q: How do you connect your local Git to GitHub?
   A: Add a remote (HTTPS/SSH) and push; or use GitHub Desktop to connect.
7) Q: What are the pros/cons of SSH vs HTTPS for Git remotes?
   A: SSH is key-based and convenient; HTTPS may prompt for credentials or token.
8) Q: How can you verify your Git installation?
   A: Run git --version or git --help to verify installation.
9) Q: Where are global Git configs stored?
   A: In the global git config file (~/.gitconfig or %USERPROFILE%\.gitconfig).
10) Q: How do you create a GitHub account?
   A: Sign up at github.com and verify your email.
